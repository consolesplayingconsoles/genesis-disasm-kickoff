A disassembly of the Mega Drive **@TITLE@**, in progress. It rebuilds the ROM byte for byte from
source generated by its tools; how far along it is, is the Progress block below.

**This repository contains no game code or data.** You supply your own ROM; `setup.sh` generates
everything game-derived on your machine, and `.gitignore` keeps it out of git.

## Building

You need your own copy of the ROM (a `.zip` holding it is fine), Python 3 with `capstone`
(`pip install capstone`), and AS, Alfred Arnold's macro assembler (`asl` and `p2bin`).

```
echo 'AS_PATH="/path/to/the folder with asl and p2bin"' > .env     # once (not committed)
bash setup.sh "path/to/your ROM"                                  # checks it, then builds
```

The build ends with `MATCH`; after a change, `bash build.sh` runs it again. The source is in `build/src/`; `AGENTS.md` is the loop for working on
it. If your `python3` is not the one with `capstone`, add `PYTHON="/path/to/that python3"` to
`.env`.

The analysis tools take the ROM path (`setup.sh` leaves it at `build/rom.bin`); run them with the
python that has `capstone`:

```
python3 tools/trace.py build/rom.bin @TRACE@ @FACTS@          # hand seeds: SEEDS in the facts
python3 tools/emit.py build/rom.bin @TRACE@ build/listing.asm @FACTS@
python3 tools/callers.py build/rom.bin @TRACE@ <hex address>
```

## What is here

| | |
|---|---|
| `@FACTS@` | the facts: identities, names, data blocks, the region map, with a confidence per entry |
| `log/notes.md` | the notes: how the engine works, what each finding rests on |
| `traces/` | the trace and the rebuild record (addresses only) |
| `tools/trace.py` | recursive-descent 68000 tracer: the game's dispatch idioms, seeds from the facts |
| `tools/rebuild.py` | the ROM as source, assembled with AS and compared; writes the rebuild record |
| `tools/progress.py` | the Progress block below |
| `tools/emit.py`, `callers.py`, `xref.py` | a listing, who names an address, who points at it |
| `tools/` (others) | the readers for the game's formats, the entropy map, patches |
| `AGENTS.md` | how to work on the disassembly |
