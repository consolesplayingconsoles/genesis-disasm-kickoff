## Building

You need your own copy of the ROM (a `.zip` holding it is fine), Python 3 with `capstone`
(`pip install capstone`), and AS, Alfred Arnold's macro assembler (`asl` and `p2bin`).

```
echo 'AS_PATH="/path/to/the folder with asl and p2bin"' > .env     # once (not committed)
bash setup.sh "path/to/your ROM"
bash build.sh
```

`build.sh` ends with `MATCH`. The source is in `build/src/`; `AGENTS.md` is the loop for working on
it.
